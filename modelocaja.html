Introducción

El modelo de caja en CSS describe cómo se representan los elementos en una página web. Cada elemento se compone de: contenido, relleno (padding), borde (border) y margen (margin). Estos definen el espacio que ocupa y cómo interactúa con otros elementos. Comprender este modelo es esencial porque permite controlar la separación entre bloques, ajustar el tamaño de los elementos y organizar la estructura visual de una página. Sin este conocimiento, los diseños pueden verse desordenados o poco claros, ya que cada parte de la caja influye directamente en cómo se distribuye el espacio.
