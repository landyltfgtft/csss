Introducción

Flexbox es un modelo de diseño en CSS que facilita la organización de elementos dentro de un contenedor flexible. Permite alinear, distribuir y ordenar los elementos de manera eficiente, adaptándose a distintos tamaños de pantalla. Las propiedades principales son display: flex, justify-content, align-items, flex-direction y flex-wrap.
