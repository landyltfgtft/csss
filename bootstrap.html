Introducción

Bootstrap es un framework de CSS que facilita el diseño de páginas web responsivas y modernas. Se puede incluir en un proyecto de dos formas: 1) Descargando los archivos y enlazándolos localmente. 2) Usando un enlace CDN (más rápido y sencillo). Además de estilos, Bootstrap incluye componentes interactivos que requieren bootstrap.min.js y Popper.js.
