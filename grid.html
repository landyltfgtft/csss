Introducción

CSS Grid es un sistema de diseño bidimensional que permite organizar los elementos en filas y columnas. Es muy flexible y facilita la creación de estructuras complejas de manera sencilla. Las propiedades principales son display: grid, grid-template-columns, grid-template-rows, gap y grid-area.
